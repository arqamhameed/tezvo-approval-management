Tezvo Approval Management

Configurable Multi-Level Approval Workflow for Odoo 19

Tezvo Approval Management is a configurable multi-level approval workflow engine for Odoo 19. It helps organizations manage approvals across Sales, Purchase, Accounting, Inventory, and Manufacturing documents using approval levels, amount thresholds, user rights, delegation, notifications, and audit history.

Key Features

  • Configurable multi-level approval workflows
  • Amount-based approval thresholds
  • Sequence-based approval levels
  • Minimum approver requirements by level
  • Company-wise approval configuration
  • Approval delegation
  • Approval history and audit trail
  • Email notifications
  • Chatter logging
  • User rights and security groups
  • Read-only protection for critical approval setup records

Supported Odoo Documents

  • Sales Orders
  • Purchase Orders
  • Customer Invoices
  • Vendor Bills
  • Customer Payments
  • Vendor Payments
  • Inventory Transfers
  • Manufacturing Orders
  • Unbuild Orders
  • Scrap Orders

Approval Delegation

Approvers can delegate approval authority to another user for a defined period. This is useful when approvers are on leave or temporarily unavailable.

  • Supports date-range validity.
  • Prevents overlapping delegations.
  • Prevents circular delegation.
  • Delegated approvals maintain approval history and audit trail.

Approval Audit Trail

Submit, approve, reject, cancel, and level transition actions are tracked.

  • Approval history includes user, date, time, level, and action details.
  • Chatter logs help users review approval activity from the related document.

Security and User Rights

Dedicated approval groups are available for controlled access and configuration.

  • Approval User
  • Approval Manager
  • Approval Admin
  • Approval Delegation Officer
  • Approval Back Rules Editor

Approval rights can be managed from the user form. Critical approval configuration records are protected, and only authorized users can amend approval setup and back-rule records.
