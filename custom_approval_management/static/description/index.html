✎ SETUP

User Guide

All-in-One Approval Hub Configuration Flow

Configure approval setups by selecting the target module, document type, company, approval levels, approvers, amount limits, and notification rules. Once applied, users can submit supported documents for approval and approvers can manage their pending requests from the centralized approval hub.

The app supports approval governance using approval requests, approval history, chatter logs, delegation records, user rights, and dedicated approval security groups.
